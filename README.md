# AnimatedPlayerDemo

> An experimental web-based music player with real-time audio frequency visualisation and
> synchronized graphical animation.

The project was created as a creative technical experiment combining music, web development 
and interactive visualisation. The visual elements respond dynamically to the characteristics of 
the playing audio, crating a viaual experience synchronized with the music.

### Features
- Web-based audio player
- Real-time audio frequency analysis
- Audio-driven visualisation
- Smooth, synchronized graphical animations
- Responsive web interface
- Custom SVG-based graphics
- Dynamic visual changes based on the frequency spectrum

### Technology
- C#
- ASP.NET Core MVC
- HTML5
- CSS3
- JavaScript
- Web Audio API
- SVG
- .NET

## How It Works

The player analyses the audio signal in real time using the Web Audio API.

Frequency data is continuously processed in the browser and used to control visual properties of 
the graphics. Theis allows the animation to react smoothly to changes in the music while the track 
is playing.

The project demonstrates how audio processing can be combined with browser-based graphics and 
animation to create an interactive user experience.

## Purpose

This project was developed as a personal experiment to explore the possibilities of combining audio 
analysis, web technologies and animation.

It is intentionally a small, focused project rather than a production-oriented application.

## Running Locally

Clone the repository and open the solution in Visual Studio.

Run the ASP.NET Core application and open the provided local URL in a modern web browser.

The project uses browser APIs for audio analysis, so a modern browser with Web Audio API 
support is recommended.
